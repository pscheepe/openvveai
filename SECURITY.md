# Security policy

OpenVvE AI is currently a beta application. Keep installations and sample data
separate from real VvE data until the hosting configuration and recovery
procedures have been reviewed.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub's
private vulnerability reporting for this repository, when available. Do not
include personal data, credentials, real VvE documents, or exploitable details
in a public issue. If private reporting is unavailable, contact the repository
maintainers through their GitHub profile and ask for a private reporting route.

There is no guaranteed response time or support service. Do not test against
installations or data that you do not own or have explicit permission to assess.

## Supported versions

Only the current maintained source release is considered for security fixes.
Older deployment patches and historical copies are not supported versions.
